# Kurdistan Strike Map · Nexşeya Êrîşan li ser Kurdistanê · نەخشەی هێرشەکان بۆ سەر کوردستان

An interactive map of state attacks and ecocide across Kurdistan, in Kurmancî, Soranî (سۆرانی), Türkçe and English.

The whole map is one file, `index.html`. It includes the records, translations, base map and code. Open it in any browser.

## Sources

Records are compiled from Kurdish media and monitoring groups, including ANF, Sterk TV, Nûçe TV, Rudaw, CPT, Hengaw, KHRN, Rojava Information Center, Synergy/Hevdestî, Airwars, PAX, HRW, Amnesty and KGNA. Province totals come from ACLED. The base map uses Natural Earth; the terrain shading comes from AWS Terrain Tiles (SRTM and other public elevation data). Every record links to its sources.

## Data

The full dataset is in `downloads/kurdistan-strike-map-records.csv`: every record with its date, place, coordinates, attacker, casualties, summaries in four languages and source links.

## Updating

The map is built from the files in `source/`. See [UPDATING.md](UPDATING.md) for how to add new records and rebuild.
